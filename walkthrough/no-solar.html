Scenario - No Existing Solar/Battery System

This guide is for users who are installing their first solar panel and/or battery system and do not currently have any existing components.

Step 1: Section 1 - Data Input Configuration

In Section 1, you need to tell the analyser you don't have an existing system:

  • Check the box labelled "No existing solar system".
  • This will automatically hide the "Solar Generation CSV" upload field, as it's not needed.
  • You still need to provide your Electricity Usage Data, either via:
    • Advanced CSV (Recommended)
    • NEM12 (Recommended)
    • Manual Mode (ToU Bill Totals)
    • Manual Mode (Flat Rate Bill Totals)

Manual Mode Note: If using Manual Mode, the "Total Import" values you enter from your bill are your total household consumption because you don't have existing solar self-consumption.

Step 2: Section 2 - Existing System Configuration

Because you checked the "No existing solar system" box in Step 1, this section becomes very simple:

  • Ensure all fields (Existing Solar Panel Size, Inverter Size, Battery Size, Battery Inverter, System Age) are set to zero (0).
  • The analyser will automatically disable some fields based on the checkbox in Section 1.

Setting these to zero ensures the Baseline calculation correctly reflects your current situation (no solar/battery) and that no degradation is applied to non-existent components.

Step 3: Configure New System & Other Sections

Now, proceed to configure the rest of the analyser sections as needed for your scenario. Click the links below for detailed guides on each section:

  • Section 3: New SystemEnter the details of the new system you are considering (panel size, battery size, costs).
  • Section 4: Financial InputsAdd loan details or discount rates if applicable.
  • Section 5: Providers & TariffsConfigure the rates and charges for the electricity providers you want to compare.
  • Section 6: Analysis PeriodSet the lifespan for the analysis and degradation rates for the new system.

Step 4: Run Analysis

Once all relevant sections are configured, click the Run ROI Analysis button in Section 7.

The results will show the financial performance of installing the new system compared to your current situation (baseline with no solar/battery).
