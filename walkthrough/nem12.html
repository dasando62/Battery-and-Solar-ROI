Guide: Importing Data (NEM12 Option)

This guide explains how to import your energy usage data using the "NEM12 Format" option. NEM12 is a standardised file format used in Australia for interval meter data, often obtainable from your energy retailer or distributor. Using this format simplifies the import process as no advanced configuration is needed.

Step 1: Select NEM12 Format

In Section 1: Data Input, select the radio button labelled "NEM12 Format".

Selecting this mode will automatically hide the "Advanced Usage CSV Options" section, as it is not required for the standard NEM12 format.

Step 2: Understand the Required Files

The NEM12 option requires at least one file:

  • Electricity Usage CSV (NEM12 Format): This file contains your interval data. You can request it from your energy retailer or distributor. It often contains multiple data streams (like grid import 'E1', grid export 'B1', and sometimes controlled load 'C1'). The analyser will automatically parse the relevant streams.
  • Solar Generation CSV (Optional but Recommended): While some NEM12 files might include gross solar generation, it's often more reliable to get this data separately from your solar inverter's monitoring system (e.g., Fronius Solar.web, Enphase Enlighten). If you have existing solar, you should upload this file to ensure accurate self-consumption calculations.

No Existing Solar? If you do not currently have a solar system, check the "No existing solar system" box. This will hide the need for a separate Solar Generation CSV file.

Step 3: Upload the Files

No advanced configuration is needed for NEM12.

  • Click the Choose File button under "Electricity Usage CSV" and select your NEM12 file. The analyser will parse grid import (E1), grid export (B1), and controlled load (C1/C2) data automatically.
  • If you have existing solar and a separate generation file (recommended), click the Choose File button under "Solar Generation CSV" and select that file. (Ensure its format matches the defaults in "Advanced Solar CSV Options", if they don't match then edit the options or save/load a config file where you've previously set them).

    • Wait for the green status messages below each button confirming the number of days loaded (e.g., "365 days of usage data loaded."). If you see errors, ensure the file selected is a valid NEM12 format CSV.

Step 4: Configure Other Analyser Sections

With your data successfully loaded via NEM12, you now need to configure the rest of the analyser. Click on the Sections below for details:

  • Section 2: Existing SystemEnter the details of your current solar panels or batteries, if any.
  • Section 3: New SystemEnter the details of the system you are considering installing (panel size, battery size, costs).
  • Section 4: Financial InputsAdd loan details or discount rates if applicable.
  • Section 5: Providers & TariffsConfigure the specific rates and charges so that the analyser can provide a comparson between the different offerings in the financial analysis.
  • Section 6: Analysis PeriodSet the lifespan for the analysis and degradation rates.

(Click the links above for detailed guides on each section.)

Step 5: Run Analysis

Once all sections are configured, scroll down and click the Run ROI Analysis button in Section 7.

The results based on your imported NEM12 data will appear below the button.
